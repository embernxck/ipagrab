# IPA Grab

Программа для Windows с окном: скачивает приложения iPhone (.ipa) из истории покупок твоего Apple ID и ставит их на айфон по кабелю. Подходит и для приложений, которые убрали из App Store твоей страны: Apple всё ещё отдаёт их тем, кто когда-то их скачивал.

## Что умеет

- **Скачать.** Подключаешь айфон, и программа показывает все приложения из App Store, которые на нём стоят, с иконками. Отмечаешь нужные и жмёшь «Скачать выбранные». Строка сверху фильтрует список, а Enter ищет в App Store.
- **Установить на айфон.** Перетаскиваешь .ipa в окно или выбираешь кнопкой, потом «Установить». Приложение ставится с оригинальной подписью Apple, переподписывать раз в 7 дней не нужно.

Скачанный .ipa привязан к Apple ID, под которым он скачан. На телефоне с другим Apple ID при первом запуске iOS один раз попросит пароль от аккаунта-владельца.

## ⚠️ Осторожно с входом

Apple может **заблокировать Apple ID** «по соображениям безопасности», если за короткое время было много попыток входа из сторонних программ. Входи один раз и аккуратно вводи пароль. Если вход не прошёл, не пробуй снова и снова. Если аккаунт всё же заблокировали, его можно разблокировать через доверенный айфон (Настройки → твоё имя) или на iforgot.apple.com.

Код 2FA Apple присылает только при верном пароле. Если пароль неверный, код просто не придёт.

## Что нужно

- Windows 10/11 x64.
- [ipatool](https://github.com/majd/ipatool/releases) для Windows. Положи `ipatool*.exe` рядом с программой, на рабочий стол или в «Загрузки», либо укажи путь в окне входа.
- Драйвер Apple для USB: приложение «Apple Devices» из Microsoft Store или iTunes.
- На айфоне при подключении нажать «Доверять этому компьютеру».

## Как это устроено

- Вход, поиск лицензии и скачивание делает **ipatool** (запускается в фоне, без консоли). Пароль Apple ID передаётся только ему, программа его не сохраняет.
- Сессию ipatool хранит в своём зашифрованном хранилище `%USERPROFILE%\.ipatool`. Пароль от хранилища программа придумывает сама и хранит в `%APPDATA%\ipagrab\config.json`, зашифрованным через Windows DPAPI, так что расшифровать его может только твоя учётная запись Windows.
- Список приложений и иконки берутся с телефона через службу Apple Mobile Device (installation_proxy, springboardservices). Установка идёт через AFC + installation_proxy. Всё это делает библиотека [idevice](https://github.com/jkcoxson/idevice).
- Поиск в App Store и иконки для найденного идут через публичный iTunes Search API.
- Больше программа никуда ничего не отправляет.

## Сборка

```powershell
cargo build --release
```

Готовый файл: `target\release\ipagrab.exe`. Рядом положи `ipatool.exe`.
